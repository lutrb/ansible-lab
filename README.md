Ansible Lab Project

Questo repository contiene i Playbook e i Roles sviluppati per la gestione dell'infrastruttura di laboratorio.

## Contenuto
- **roles/:** Contiene il Role 'test_role' generato.
- **inventory:** File di inventario per definire i Managed Nodes.

## Come Usare
1. Clonare il repository.
2. Eseguire i Playbook con: ansible-playbook nome_file.yml
